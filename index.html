ColorMaster

Color, gradientes y mezclas reales de pigmentos para artistas

Aplicación de escritorio (PySide6) para artistas que trabajan con acuarela, acrílico y óleo: elige un color, genera sus gradientes de brillo/saturación/tono/luminosidad, gestiona tu paleta real de pigmentos y descubre qué proporción de tus tintas necesitas mezclar para conseguir un color objetivo.

Funciona con catálogos de fabricantes, paletas personales en SQLite y un motor de mezcla basado en una aproximación de Kubelka-Munk. Añadir tus propias tintas o fabricantes no requiere tocar el código.

Selector y gradientes

Selector tipo Photoshop (hex, RGB, CMYK) con color complementario automático y 5 gradientes de 10-27 pasos: brillo, saturación, tono, luminosidad y transición libre entre dos colores.

Catálogos y paleta real

Explorador de catálogos de fabricantes con carga perezosa (solo el Excel que decides abrir) y paleta personal en SQLite, con varias paletas con nombre y todos los datos del pigmento copiados localmente.

Mezcla óptima

Dado un color objetivo y tu paleta, calcula qué proporción de hasta 4 pigmentos se aproxima más, con el ΔE del resultado, usando un modelo de mezcla más realista que el promedio RGB.

PySide6 Color matemático Kubelka-Munk SQLite Multi-fabricante

Qué es ColorMaster

Una herramienta de escritorio para artistas que quieren entender y controlar el color de sus pigmentos reales: desde la elección de un color hasta la mezcla exacta con sus propias tintas.

ColorMaster separa claramente la lógica de color (sin dependencias de Qt) de la interfaz y de la base de datos. El núcleo matemático convierte entre HEX, RGB, HSV, HSL, CMYK y Lab, y genera gradientes. El mezclador usa una aproximación de Kubelka-Munk de constante única aplicada a cada canal RGB, ponderada por la opacidad de cada pigmento, lo que da resultados más realistas que promediar RGB directamente.

La aplicación está pensada para que puedas añadir tus propias tintas y fabricantes sin tocar el código: desde la propia interfaz, con un diálogo que admite color directo en hex o valores L*a*b*, y con control de opacidad y fiabilidad del dato.

Características principales

Color y gradientes

  • Selector de color tipo Photoshop (hex, RGB, CMYK).
  • Color complementario automático.
  • 5 gradientes de 10-27 pasos configurables: brillo, saturación, tono, luminosidad y transición libre entre dos colores.

Catálogos de fabricantes

  • Explorador con carga perezosa: solo se lee el Excel del fabricante que decides explorar.
  • Filtro por tipo de tinta y buscador por nombre.
  • Índice ligero pigment_index.xlsx cargado siempre al arrancar.

Paleta personal

  • Guarda qué pigmentos tienes, de cualquier fabricante, en SQLite.
  • Varias paletas con nombre.
  • Cada pigmento guardado copia sus propios datos (nombre, marca, tipo, hex, opacidad): mostrar la paleta o calcular una mezcla nunca necesita releer un Excel de fabricante.

Mezcla y historial

  • Sugerencia de mezcla óptima con hasta 4 pigmentos y ΔE del resultado.
  • Historial de colores seleccionados y mezclas calculadas.
  • Exportación/importación del historial a archivo.
  • Exportación a PDF de un informe completo (color master, gradientes, paleta, mezcla, historial reciente).

Añadir tus propios pigmentos

  • Fabricante nuevo o tinta de un fabricante ya existente.
  • Color introducido a mano: hex directo o valores L*a*b*.
  • Control de opacidad (0 = transparente, 1 = opaco) y fiabilidad (1-5).
  • La tinta queda disponible al instante para añadirla a tu paleta.

Interfaz

  • Interfaz en español.
  • Tema claro/oscuro.
  • Arquitectura clara: core/ sin Qt, ui/ PySide6, database/ SQLite.

Instalación y uso rápido

Instalación

git clone <url-del-repositorio>
cd ColorMaster
pip install -r requirements.txt

Requiere Python 3.10+ y Windows, macOS o Linux con soporte para PySide6.

Ejecutar la aplicación

python main.py

Abre el panel derecho, sección "Explorar catálogo de un fabricante" para cargar catálogos, o usa "+ Añadir fabricante o tinta" para incorporar tus propios pigmentos.

Añadir tus propias tintas

# Desde la app:
1. Panel derecho → "Explorar catálogo de un fabricante"
2. "+ Añadir fabricante o tinta"
3. Elige marca y tipo (existente o nuevo)
4. Escribe el nombre del color
5. Elige color directo (hex) o valores L*a*b*
6. Ajusta opacidad (0-1) y fiabilidad (1-5)
7. Guarda

Añadir tus propias tintas y fuentes de datos

Desde la aplicación (sin tocar código)

El diálogo "+ Añadir fabricante o tinta" permite crear un fabricante nuevo o añadir una tinta a uno existente. Puedes dar el color directamente en hex o introducir valores L*a*b* si tienes una ficha técnica. La opacidad y la fiabilidad del dato se ajustan con controles deslizantes.

De dónde sacar valores L*a*b* reales

La web artistpigments.org tiene mediciones CIE L*a*b* reales de miles de colores de cientos de marcas, hechas con espectrofotómetro. Es la fuente recomendada para tintas puntuales que tú mismo uses.

1. Crea una cuenta gratuita en artistpigments.org
2. Busca tu marca y el color exacto
3. Anota L*, a*, b* y la categoría de transparencia
4. En ColorMaster usa el modo "Introducir valores L*a*b*"
5. Equivalencia de opacidad:
  Opaque → 0.90
  Semi-Opaque → 0.65
  Semi-Transparent → 0.40
  Transparent → 0.15
6. En "fuente" escribe: artistpigments.org (cuenta propia) - [marca]
7. Fiabilidad: 4

⚠️ Importante — licencia: el contenido de artistpigments.org está bajo licencia CC BY-NC 4.0 (uso no comercial, con atribución). Es correcto para tu paleta personal, pero no se debe redistribuir un volcado masivo de sus datos como parte de la base de datos oficial de este repositorio. Por eso ColorMaster no incluye ningún catálogo extraído de artistpigments.org.

Ampliar la base de datos oficial (mantenedores)

Requiere encontrar una fuente oficial, pública y gratuita con valores numéricos de color (no cartas en PDF sin datos, no fuentes con login) para incluirla como catálogo con fiabilidad alta.

# 1. Convertir un CSV con columnas Nombre,Tipo,L,a,b,Opacidad
python utils/conversor_lab_hex.py --input data_sources/mi_fabricante.csv \
  --output database/mi_fabricante_convertido.xlsx \
  --fuente "Mi Fabricante Official" --marca "Mi Fabricante" --fiabilidad 5

# 2. Añadir una entrada en database/build_index.py (lista SOURCES)

# 3. Regenerar el índice
python database/build_index.py

Arquitectura y estado del proyecto

ColorMaster separa el núcleo matemático de la interfaz y de la base de datos, lo que permite usar la lógica de color y mezcla como biblioteca independiente.

Componentes principales ├── core/color_math.py # Conversiones HEX/RGB/HSV/HSL/CMYK/Lab y gradientes (sin Qt) ├── core/mixer.py # Modelo de mezcla Kubelka-Munk de constante única por canal RGB ├── database/db_manager.py # Paletas de usuario en SQLite (datos copiados localmente) ├── database/pigment_index.xlsx # Índice ligero marca+tipo, cargado al arrancar ├── ui/ # Interfaz PySide6 (temas claro/oscuro en resources/) ├── utils/ # Conversor Lab→hex, historial, exportación a PDF ├── data_sources/ # CSV originales usados para construir catálogos oficiales └── main.py # Punto de entrada

El proyecto incluye el catálogo oficial de Daniel Smith Acuarela (214 colores) con datos publicados por el propio fabricante. Cualquier dato que añadas tú mismo desde artistpigments.org u otra fuente queda en tu base de datos local (SQLite, no se sube a este repositorio) y conserva los términos de esa fuente.
